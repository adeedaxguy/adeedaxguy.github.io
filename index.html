Owner-operated desktop app

Publishing for MMA News Daily

This Windows application is for the owner of the MMA News Daily YouTube channel. It does not offer public accounts or access to other channels.

The app uses the official YouTube Data API after the owner grants Google OAuth access. It checks the authorized channel, uploads an approved video as Unlisted, sets its title, description, tags and thumbnail, and checks YouTube processing and saved status. It changes that same video ID to Public only after its release checks pass. If a check fails, the job and saved evidence remain for correction.

Owner control: The owner has instructed the app to begin with Unlisted visibility and make a video Public only after the required source, rights, review, processing and release checks pass. The production schedule is enabled only after full pilots prove those checks.

Google access requested

The app requests https://www.googleapis.com/auth/youtube.force-ssl. This is a broad YouTube management permission, including capabilities the app does not use. The current app uses it to identify the channel, upload and update videos and metadata, set thumbnails, and read back processing and visibility. It does not call deletion, comment, rating or caption endpoints. The app never asks for the owner's Google password.

Read the privacy and YouTube data notice before granting access. For questions, contact adnan@technodigg.com.
